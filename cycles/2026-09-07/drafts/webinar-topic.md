# Webinar topic proposal — not a CMS write

**Working title:** Running Multiple Gym Locations Without Losing Control

**Abstract:** For coaches and gym owners scaling past one location, the hard
part isn't opening the second site — it's knowing which location and which
coach is actually making money, and paying everyone correctly without weeks
of manual reconciliation. This session walks through a practical operating
model — per-location and per-coach revenue visibility, automated payouts, and
attendance accountability — using TrainZilla's franchise tools as the working
example.

**5-point outline:**
1. Why per-location revenue reporting alone isn't enough — the missing per-coach layer
2. Setting up automatic coach payouts (Razorpay Route) so revenue share pays itself
3. Coach attendance tracking across sites — connecting presence to performance
4. Migrating an existing client roster with bulk CSV import when you switch software
5. Live Q&A: franchisor view vs. franchise-owner view of the same dashboard

**Primary keyword targeted:** multi-location gym management software (supporting: gym franchise management software)

**Feature anchors:** per-location & per-coach revenue dashboards `[GAP]`, Razorpay Route payouts `[GAP]`, coach attendance tracking `[GAP]`, bulk CSV client import `[PARTIAL]`
